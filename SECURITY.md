# Security Policy

## Supported Versions

Security patches are only provided for the latest major version. Older versions will not receive
retroactive security patches.

## Reporting a Vulnerability

Please do not create a public GitHub issue. This repository has
[private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/privately-reporting-a-security-vulnerability)
enabled. To confidentially report a security issue, click the **"Report a vulnerability"** button on
the [Security tab](../../security/advisories/new) of this repository. This allows you to submit
details without public disclosure.
